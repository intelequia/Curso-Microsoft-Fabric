# Ejercicio 3 (Jornada 2) · Observabilidad y checklist de producción

**Tiempo estimado:** 90 min · **Modalidad:** casa

## Objetivo

Revisar trazas, diseñar evaluación continua y preparar un checklist de producción.

## Pasos

1. Ejecuta la batería de `assets/data/eval_questions.csv` contra tu agente.
2. Anota para cada pregunta:
   - Respuesta.
   - Fuente citada.
   - Tool calls.
   - Resultado esperado.
   - Aprobada / fallida.
3. Revisa trazas de una respuesta correcta y una fallida.
4. Propón tres mejoras:
   - Instrucciones.
   - Knowledge base.
   - Herramientas o permisos.
5. Completa el checklist:
   - Identidad.
   - RBAC.
   - Red privada.
   - Retención de conversaciones.
   - Monitorización.
   - Evaluación continua.
   - Red teaming.

## Entregable

Documento máximo 3 páginas con resultados, evidencias y checklist.

## Validación

- [ ] Hay tabla de evaluación.
- [ ] Hay al menos una traza analizada.
- [ ] El checklist diferencia piloto y producción.
