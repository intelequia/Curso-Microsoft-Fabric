# Ejercicio 1 (Jornada 1) · Crear proyecto y desplegar modelo

**Tiempo estimado:** 45 min · **Modalidad:** aula / casa

## Objetivo

Crear un proyecto Microsoft Foundry y desplegar un modelo usable desde playground y código.

## Prerequisitos

- Suscripción Azure activa.
- Permiso para crear recursos.
- Acceso a `https://ai.azure.com`.

## Pasos

1. Crea el resource group `rg-ia-ml-azure-aurora`.
2. Entra en Microsoft Foundry.
3. Crea el recurso `foundry-aurora` y el proyecto `foundry-aurora-curso`.
4. Abre Model catalog.
5. Despliega un modelo compatible en tu región.
6. Prueba en playground:

   ```text
   Explica en dos frases que es Microsoft Foundry.
   ```

7. Anota:
   - Nombre del deployment.
   - Endpoint del proyecto.
   - Región.
   - Modelo y versión.

## Entregable

Captura del modelo desplegado y respuesta del playground.

## Validación

- [ ] El proyecto existe.
- [ ] Hay un modelo desplegado.
- [ ] El playground responde correctamente.
