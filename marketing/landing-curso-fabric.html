No es otro curso de "dónde está el botón"

Formación con criterio: tu equipo aprende a elegir la pieza correcta de Fabric para cada caso y a construir, gobernar y explotar la plataforma con confianza.

⚡

Caso de negocio end-to-end

Todo el curso gira en torno a Aurora Energía, una compañía ficticia con estaciones de servicio, comercializadora eléctrica y logística. Cada ejercicio construye sobre el anterior: el alumno termina con un entorno analítico completo y funcional sobre su propio trial de Fabric.

🧭

Criterio arquitectónico

¿Lakehouse o Warehouse? ¿Dataflow Gen2 o Pipeline? ¿Eventhouse o Spark Streaming? Aprenderás a elegir la pieza correcta para cada escenario y a planificar una hoja de ruta de adopción realista para tu organización.

📦

Material que se queda contigo

Repositorio completo con teoría, packs de ejercicios para casa (~3–4 h por jornada) con checklist de validación, datasets sintéticos, scripts SQL/KQL, notebooks PySpark y canal de soporte asíncrono entre jornadas.

🛡️

Gobierno desde el día uno

Una jornada completa dedicada a Microsoft Purview: Data Map, catálogo unificado, clasificación, etiquetas de sensibilidad y DLP, integrados extremo a extremo con Fabric. El dato gobernado es la base de cualquier estrategia de IA.

Lo último: Fabric IQ y Data Agents

Construirás un Data Agent real capaz de responder preguntas en lenguaje natural sobre los datos corporativos, y conocerás el roadmap de Fabric IQ: Ontology, Graph y agentes de operaciones.

Preguntas frecuentes

¿Qué necesita el alumno antes de empezar?
Una cuenta Microsoft Entra ID (corporativa o trial) con permiso para activar el trial gratuito de Fabric (60 días), y tener instalados Power BI Desktop, VS Code y Git. Entregamos una guía de preparación paso a paso y, si hay restricciones corporativas, coordinamos alternativas con antelación.
¿Hace falta experiencia previa en Microsoft Fabric?
No. El curso empieza desde los fundamentos. Son recomendables conocimientos básicos de SQL y, para la jornada opcional de MLOps, nociones de Python.
¿Tiene coste de plataforma para la empresa?
No durante el curso: cada alumno trabaja sobre el trial gratuito de Fabric de 60 días. Si tu organización ya dispone de capacidad Fabric, podemos usar workspaces dedicados sobre la misma.
¿En qué modalidades se imparte?
Presencial, remoto en directo o mixto, para grupos de hasta 25 alumnos. Las jornadas de 4 horas se adaptan al calendario de tu equipo (2 ó 3 jornadas, consecutivas o espaciadas). La formación es bonificable a través de FUNDAE.
¿La jornada de MLOps es obligatoria?
No, es opcional. El núcleo del curso son las jornadas 1 (Fabric) y 2 (Purview + Fabric IQ), 8 horas en total. La jornada 3 amplía a 12 horas con el ciclo MLOps completo, recomendada si tu equipo tiene perfiles de Data Science o quiere explotar las capacidades de ML de Fabric.
¿Qué soporte hay después de las clases?
Entre jornadas se habilita un canal de soporte asíncrono (Teams o repositorio de issues) para resolver dudas de los ejercicios para casa. Además, todo el material queda disponible para uso interno del equipo.
