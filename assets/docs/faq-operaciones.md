# Aurora Energía · FAQ de operaciones

## Punto de recarga no disponible

Si un punto de recarga aparece como no disponible:

1. Verificar conectividad del cargador.
2. Revisar alarmas del proveedor.
3. Validar si hay mantenimiento programado.
4. Si afecta a más de tres cargadores en una estación, clasificar como severidad alta.
5. Si afecta a varias provincias, clasificar como crítica.

## Reclamación de cliente

Las reclamaciones deben gestionarse desde el portal interno de atención. El asistente puede resumir el procedimiento, pero no debe mostrar datos personales del cliente.

## Cierre diario

El cierre diario debe validar ventas, incidencias abiertas, conciliación de pagos y estado de estaciones críticas antes de las 22:00.
