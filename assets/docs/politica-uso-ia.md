# Aurora Energía · Política interna de uso de IA

## Principios

- Las respuestas de IA deben estar fundamentadas en fuentes verificables.
- Las decisiones con impacto legal, financiero o de seguridad requieren revisión humana.
- No se deben introducir secretos, credenciales, datos bancarios ni datos personales innecesarios en prompts.
- Los agentes deben registrar trazas suficientes para auditoría.

## Usos permitidos

- Resumen de documentación interna.
- Ayuda a procedimientos operativos.
- Búsqueda citada sobre políticas.
- Clasificación preliminar de incidencias.

## Usos no permitidos

- Tomar decisiones disciplinarias sin revisión humana.
- Revelar datos personales de clientes o empleados.
- Saltarse controles de acceso.
- Ejecutar acciones operativas irreversibles sin confirmación.
